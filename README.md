### GitHub README Project Description

# 🧠 AI-Powered Brain Tumor Detection System

An end-to-end Deep Learning-based healthcare application that automatically detects and classifies brain tumors from MRI scans using the VGG16 Transfer Learning model. The system classifies MRI images into four categories: **Glioma**, **Meningioma**, **Pituitary Tumor**, and **No Tumor**, achieving an overall accuracy of **99.18%**.

The project combines Artificial Intelligence with modern web technologies to provide a real-time, user-friendly diagnostic support tool for healthcare professionals.

## 🚀 Features

* Multi-class Brain Tumor Classification
* VGG16 Transfer Learning Architecture
* MRI Image Preprocessing and Augmentation
* High Accuracy (99.18%)
* React + Vite Frontend
* FastAPI Backend
* Real-Time MRI Upload and Prediction
* REST API Integration
* Deployable Healthcare-Oriented Web Application

## 🏥 Problem Statement

Brain tumor diagnosis from MRI scans requires expert radiologists and significant time for analysis. Manual interpretation may lead to variability and delayed diagnosis. This project aims to assist healthcare professionals by providing an AI-based automated classification system that delivers fast, reliable, and consistent predictions.

## 🧠 Model Details

* Base Model: VGG16 (Pretrained on ImageNet)
* Input Size: 224 × 224
* Optimizer: Adam
* Loss Function: Categorical Cross-Entropy
* Batch Size: 32
* Epochs: 10
* Train-Test Split: 80:20
